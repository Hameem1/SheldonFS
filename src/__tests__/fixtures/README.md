# Test Fixtures

This directory contains minimal binary files used for testing MIME type detection and file processing.

## Files

All fixture files are **tiny** (< 2KB each) and are either:
- Generated programmatically
- From public domain sources
- Created specifically for testing

## Adding New Fixtures

When adding fixtures:
1. Keep file size minimal (< 2KB preferred)
2. Document the source/license
3. Use public domain or CC0 licensed content
4. **Never commit personal files**
